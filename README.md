# Иврит шаг за шагом

Курс современного иврита для самостоятельного изучения: уровни Алеф и Бет, интервальное повторение, чтение, прописные буквы.

Открыть приложение: https://jugrec.github.io/ivrit/

Прогресс хранится только на вашем устройстве. Чтобы перенести его, используйте «Настройки → Прогресс → Сохранить копию в файл» и «Загрузить копию».

Шрифт прописных букв: Ktav Yad CLM (Maxim Iorsh, Culmus project, GNU GPL v2).
