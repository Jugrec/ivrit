# Приложение «Иврит шаг за шагом»: состояние работы

Этот файл нужен, чтобы продолжить работу в новом чате. Новый чат начинать внутри проекта «ИВРИТ ПРИЛОЖЕНИЕ» и сначала прочитать этот файл.

## Где что лежит
- Опубликованное приложение (artifact): https://claude.ai/artifact/4QQQox55GcGM1EE4WXj2BW. Обновлять публикацией по этому url, не создавать новый (иначе пропадёт ссылка и прогресс).

## Как восстановить рабочую папку в новом чате
1. Скачать все файлы из claude/ivrit-app/ (project_read) в /home/claude/ivrit/: index.html в корень, *.json в content/, build/*.py в build/.
2. Проверить локально (python http.server с UTF-8 + Playwright, window.claude замокан, localStorage-fallback).
3. Публиковать: Artifact publish, file_path /home/claude/ivrit/index.html, url выше, root /home/claude/ivrit, files {"content/x.json": "content/x.json"} для изменённых файлов.
4. После изменений сохранять файлы обратно в проект (project_write с local_path).

## Методика и решения
- Ульпан, уровни Алеф–Хей, объяснения на русском, без религиозного иврита. 30–60 мин в день.
- FSRS-повторения (карточки w:<слово>, k:<навык>), адаптивная сложность (≥90% → усложнение), «Сдать досрочно» (7 из 8).
- Огласовки убираются постепенно, переключатель есть. Транслитерация кириллицей вначале. Прописные для ознакомления.
- Звука нет (на Android нет голоса иврита; платные сервисы не используем).
- В ответах ученице не использовать тире (—).
- Модуль открывается после всех уроков предыдущего.
