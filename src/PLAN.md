# План доработок (пункты 2-9 и речь): задание и правила работы

## Правила экономной работы
1. Один пункт = один цикл: данные → код → одна автоматическая проверка → один браузерный прогон → публикация (artifact + deploy_site.sh + project_write). Не начинать следующий пункт, пока текущий не проверен.
2. Ивритский материал писать сразу в источник (build/*_src/*.txt или JSON) компактным форматом, без повторного вывода в чат. Проверка скриптом: огласовки, отсутствие латиницы и тире, повторы, сверка со словами курса.
3. Самопроверка содержания: один проход глазами по списку «слово → форма» (выводить только сжатую строку), исправлять точечно (sed/python replace), без перечитывания целых файлов.
4. Код вставлять одним python-патчем с assert на уникальность фрагмента; не читать index.html целиком, только grep -n и узкие диапазоны.
5. Тест: один node/playwright-скрипт на пункт, печатает только ошибки и 5-10 строк образцов. Скриншот только для нового экрана.
6. Не дублировать: использовать существующий движок заданий (run, choice/type/order), FSRS, summary, карточки v:/k:.
7. В ответе ученице: коротко, что появилось и где, без пересказа процесса. Без тире.

## Пункты и критерии готовности
1. ✓ Чтение без огласовок (версия 34).
2. ✓ Корни и модели слов (версия 35). Данные: ~40 частотных корней × 3-6 слов (семья корня) + ~15 моделей (мишкаль/биньян) с примерами. Режимы: «семья корня» (карточки), «собери слово» (корень + модель → слово и смысл, выбор/ввод). Готово: все слова с огласовками сверены с курсом, модели дают реальные слова.
3. ✓ Истории-сериал (версия 36). 10 эпизодов по 80-150 слов, одни герои, лексика Алеф-Бет. Скрипт считает покрытие известными словами (цель ≥95%), неизвестные слова одним нажатием в «Слова дня». Вопросы на понимание к каждому эпизоду.
4. ✓ Карточки-предложения с пропуском (версия 38). Для «Слов дня» с примерами: пропуск слова в предложении (форма из примера), ввод с проверкой (опечатки как в уроках). Готово: пропуск совпадает с формой в примере.
5. ✓ «Строим фразы» (версия 39). Цепочки из 4-6 шагов (русская фраза → иврит), 20 цепочек по слабым темам: будущее время, hифъиль, предлоги с окончаниями, числительные, смихут. Ввод с проверкой, принимаются варианты.
   Дневник: 3 предложения в день; в Claude проверка Claude, на сайте чек-лист и образцы.
6. ✓ (версия 40) Карта навыков: сетка тем с цветом по стабильности карточек k:; кнопка «Тренировка слабых тем» (3 самых слабых навыка, 15 заданий), раз в неделю напоминание.
7. ✓ (версия 42) «Пиявки»: слово забыто 4+ раз → список, карточка в контексте, сравнение с похожим словом; мнемоники заранее для частых.
8. ✓ (версия 43) Готовые фразы и ситуации: ~120 разговорных выражений по 8 ситуациям (врач, банк, аренда, звонок, магазин, транспорт, знакомство, работа) как тема «Слов дня» + мини-диалоги с выбором реплики.
9. ✓ (версия 44) Контрольные в формате экзамена ульпана (Алеф, Бет): понимание текста, грамматика, сочинение (Claude проверяет в Claude-режиме).
10. ✓ (версия 45) Ситуации, вариант 3 (Юлия попросила напомнить после пункта 9): у каждой реплики собеседника 2-3 варианта и неверные ответы из пула ловушек, случайно при каждом заходе; по 4-5 диалогов на ситуацию, выбирается непройденный или пройденный хуже.
Речь: проверка SpeechRecognition (he-IL) на телефоне; если работает, режим «скажи слово/фразу» с сравнением. Аудио-подборка ссылок по темам.
